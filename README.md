## ⚙️ Instalación y Ejecución del Proyecto

1. **Clonar el repositorio desde GitHub:**
   git clone https://github.com/eluneymoure77/Parcial2-Vue-SNK.git
   cd Parcial2-Vue-SNK

## Project Setup

### Instalar dependencias:

```sh
pnpm install
```

### Configurar variables de entorno (ver siguiente sección).

Creá un archivo .env en la raíz del proyecto (no se sube a GitHub) con la siguiente variable:

````env
VITE_OPENROUTER_API_KEY=tu_api_key_de_openrouter

### Correr el servidor de desarrollo:
```sh
pnpm dev
````

### Compilar para producción:

```sh
pnpm build
```

### Lint with [ESLint](https://eslint.org/)

```sh
pnpm lint
```
